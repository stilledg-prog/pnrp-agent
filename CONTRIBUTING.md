# Contributing

## Padrões
- Não inclua PII real (repo público).
- Mantenha `rule_id` estável em `protocol/rules.json`.
- Toda mudança em schemas deve acompanhar exemplos atualizados em `examples/`.

## Pull Requests
- CI deve passar (`.github/workflows/ci.yml`).
- Evite commits com artefatos grandes (PDFs, imagens, vídeos).
