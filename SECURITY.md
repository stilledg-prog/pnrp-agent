# Security Policy

## Reporting a Vulnerability
Se você identificar risco de exposição de dados pessoais (PII) ou falha que permita inferência de PII:
- Não abra issue pública.
- Reporte de forma privada ao mantenedor do repositório.

## Public Repo Rules
- É proibido versionar PII real.
- Artefatos reais devem ser referenciados por `storage_ref` e hashes.
